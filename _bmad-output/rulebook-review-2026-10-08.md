# 룰북 독립 재검토 — Lighthouse Complete Edition + Logbook Journal

작성일: 2026-10-08. 기존 구현·정보구조·src를 보지 않고 Complete Edition PDF 96쪽과 Logbook Journal PDF 40쪽을 처음부터 끝까지 읽은 뒤 작성했다. 아래 `p.`는 Complete Edition 인쇄 쪽수이며, `PDF`는 파일 내 1부터 시작하는 페이지다. 본문 인쇄 p.1은 PDF 7, 대체로 PDF = 인쇄 + 6. 로그북은 PDF 페이지로 표기한다.

## 1. 게임이 실제로 요구하는 경험

혼자 하는 성찰적·명상적 저널링 게임이다. 밤마다 등대 불빛을 유지하고 자신과 등대를 돌보고 관찰한 내용을 기록한다. 15분 정도의 짧은 기록도, 긴 기록도 모두 허용된다. 매일의 효율·점수·승패·제한된 임무 횟수를 달성하는 게임이 아니다. 자신의 관점 또는 선택한 가상 등대지기 관점으로 플레이한다. 프롬프트는 모두 해석 가능하고, 감정·반응·행동·눈에 띈 세부사항이 기록의 핵심이다. (p.2–4, PDF 8–10)

등대지기 의무는 일몰부터 일출까지 불빛 유지, 등대 관리, 불빛 감시, 업무와 관찰의 기록이다. (앞부분 PDF 6)

### 실제 기본 플레이 루프

1. **시작 — 세션마다 한 번**: 날짜·시간을 기록하고 → 자신/등대지기의 감정으로 날씨를 선택하고 서술 → 동전과 카드 한 쌍을 뒤집어 점등 성공까지 반복 → 성공 후 빛을 회전시키는 태엽을 감는다.
2. **밤 — 원하는 만큼 반복**: 날씨 또는 하고 싶은 이야기로 임무(관찰·정비·사건)를 선택 → 해당 임무의 판정 도구로 결과를 얻음 → 결과를 자유 해석하여 저널에 수행 방법·반응·결과를 기록 → 다시 임무 목록으로 돌아가 다음 임무를 선택.
3. **끝 — 플레이어가 결정**: 등대 상태/그날 플레이에 만족하면 불빛을 끈다 → 밤의 분위기를 돌아보며 정해진 횟수만큼 카드 덱을 섞는다 → 마지막 소감/남은 일 기록 → 로그북을 제자리에 돌려놓는다.

근거: 전체 순서 p.5(PDF 11); 시작 p.35–38(PDF 41–44); 밤 p.40–47(PDF 46–53); 끝 p.48–49(PDF 54–55).

**설계상 우선순위**: 쓰기 공간과 당장 필요한 규칙·판정이 같은 작업 맥락에 있어야 한다. 각 결과는 기록으로 연결되고, 기록 뒤 다음 임무 선택까지 즉시 복귀해야 한다. 규칙이나 원래 PDF를 찾느라 기록 도구를 떠나거나 메뉴를 반복 탐색하는 것이 가장 큰 마찰이다. 시작 설정은 세션에 한 번; 계절·플레이북·미니게임은 보조다. 기존 기능 보존보다 이 흐름을 지키는 것이 중요하다.

## 2. 시작 절차와 정확한 규칙

### 처음 관찰 (p.35–36, PDF 41–42)

- **매 기록은 시간과 날짜로 시작**해야 한다.
- **날씨는 주사위로 정하지 않고 선택**한다. 가상 인물의 상태나 본인의 실제 감정으로 여덟 가지 중 선택한다.
- 날씨는 밤의 전체 분위기를 정한다. 기온·보이는 것·소리를 서술하고, 낮에 어떤 영향을 주었는지와 현재 날씨에서 임무를 수행하는 감정을 기록한다.
- Logbook Journal의 정형 항목은 `Keeper Name`, `Keeper No.`, `Observations taken on [date] at [time]`, `Temp`, `Winds`, `Sights`, `Remarks`다. (로그북 PDF 3–38)

### 감정→날씨 (p.37, PDF 43; 원본 시각 확인)

| 감정 | 날씨/서술 출발점 |
|---|---|
| 피곤함·기운 없음 | 우주 끝에서 거센 폭풍이 올라와 혼란을 일으킴 |
| 아픔·불편함 | 거친 태양풍; 바람의 휘파람/노래/외침/속삭임은 무엇을 말하는가 |
| 행복함 | 춥고 맑은 밤; 눈 같은 우주 먼지가 땅을 덮음 |
| 신남 | 따뜻함; 좋은 날씨를 즐기는 생물과 우주선이 더 많음 |
| 화남 | 기이한 빛이 하늘에서 춤춤; 대낮처럼 강렬함 |
| 편안함·차분함 | 약하게/세차게/폭우로/불규칙하게 비가 옴; 시야 제한 |
| 슬픔·침울함 | 유성우; 탑 가까이 지나고 번쩍임과 충돌 소리가 남 |
| 불안함 | 고요하고 맑은 밤; 기묘한 정적/편안한 침묵/불길한 고요 |

### 점등 (p.38, PDF 44; 원본 시각 확인)

- 매 시도에 **동전 1개와 카드 1장**을 뒤집는다.
- **동전 앞면 + 빨간 카드가 같은 시도에서 나와야 성공**한다. 빨간 카드 문양은 하트/다이아몬드다.
- 실패하면 계속 시도한다. 이전 앞면과 다음 시도의 빨간 카드를 조합하면 안 된다.
- 어려움을 겪었으면 이유 한 문장을 쓴다. 날씨·떨리는 손·젖은 심지·피로·장치 고장 등의 서술.
- 성공하면 **태엽 장치를 감아서 빛을 회전**시킨다. 성공 판정과 회전 시작은 같은 개념이 아니다.
- 숫자 난이도·성공률 보정·성공 강제·시도 상한은 없다. 실패 횟수를 기록으로 남기는 것은 유용하지만 벌점을 만들면 안 된다.

## 3. 밤 임무 선택과 반복

날씨 또는 원하는 이야기를 기준으로 선택한다. 아래는 권유이며 임무 선택을 강제하거나 자동 순환시키지 않는다. 완료 및 기록 후 다시 목록에 돌아온다. (p.40–41, PDF 46–47)

| 밤의 느낌 | 권장 임무 |
|---|---|
| 불안정함/unsettling | 관찰 |
| 거침/wild | 정비 |
| 불확실함 | 사건 |
| 조용하고 방해 없음 | 사건 |
| 추움 | 정비 |
| 시끄럽거나 혼란스러움 | 사건 |
| 숨 막히게 더움 | 정비 |
| 잘 모르겠음 | 생각을 정리하고 관찰 |
| 이상함 | 정비 |
| 차분함 | 관찰 |

원문은 quiet=사건, calm=관찰이므로 둘을 합쳐 자동 추천하면 틀린다. 비·유성우 등 날씨명과 위 서술의 관계는 해석 가능하고 하나의 임무로 결정되지 않는다.

### 정비 (p.42–43, PDF 48–49)

**주사위 1d6로 과제 → 카드 문양으로 진행 결과 → 수행·결과를 기록**. p.42–43 지면은 카드 설명이 먼저 나오지만 플레이북 설명 p.8(PDF 14)이 "roll the die ... then flip the card"를 명시한다. 구현 순서는 주사위 후 카드 또는 두 도구의 결과를 단계가 명료하도록 순차 표시하는 것이 원문 전체와 맞는다.

| d6 | 과제 | 서술 예 |
|---|---|---|
| 1 | 무언가 부서지거나 금이 감 | 유리창·렌즈·마음·뼈·의지·컵·등대 벽 |
| 2 | 무언가 풀리거나 해체됨 | 파이프·밧줄·인내심·옷의 실 |
| 3 | 무언가 돌봄이 필요함 | 다친 생물·물에 손상된 계단·등유·차 |
| 4 | 무언가 없어지거나 잘못 놓임 | 열쇠·로그북·여행자·희망·24시간·믿음·로그북의 페이지 |
| 5 | 무언가 삐걱거리거나 기울거나 소리를 냄 | 빛의 기어·문 경첩·액자·마룻장 |
| 6 | 무언가 정리·질서가 필요함 | 기록 책상·아래층 바닥·문 옆 선반 |

| 문양 | 진행 결과 |
|---|---|
| ♠ | 과제를 완료하면서 예상치 못한 일이 일어남 |
| ♣ | 일이 자신에게 유리하게 돌아가지 않음 |
| ♥ | 과제 중 기억이 떠오름 |
| ♦ | 일이 자신에게 유리하게 돌아감 |

결과는 **성공/실패 이진 판정이 아니라 서술 프롬프트**다. 완료 방법·결과·등대 변화·수행 장소를 쓴다. 어려움이 있다면 부상·오래된 부상 악화·날씨·피로·생각거리·까다로운 일 등 이유를 적는다. 자신도 등대만큼 돌봄 대상이다.

### 관찰 (p.44–45, PDF 50–51)

**1d6으로 대상 → 카드 문양으로 거리 → 관찰을 기록**.

| d6 | 대상 | 서술 예 |
|---|---|---|
| 1 | 동물 | 우주 고래·은하 가오리·날개 생물·태양 물고기·곤충 |
| 2 | 우주선 | 전투함·정찰선·호화선·교역단·개인 우주선 |
| 3 | 하늘의 무언가 | 오로라·유성우·행성·안개·번개·죽어가는 별·신기루 |
| 4 | 구조물 | 떠다니는 도시·이동 우주정거장·탈출 포드·교역항 |
| 5 | 외계 존재 | 미지의 생물·미표식 우주선·미기록 동물·UFO |
| 6 | 존재들/beings | 우주 보행자·해적·여행자·탐험가·로봇 |

| 문양 | 거리 |
|---|---|
| ♠ | 먼 곳의 점·빛의 번쩍임·별 사이 희미한 얼룩 |
| ♣ | 등대 빔 바로 너머의 안전한 거리 |
| ♥ | 섬에서 팔이 닿을 만큼 가까움 |
| ♦ | 머리 위 |

배: 목적·출발지·행선지·탑승자를 상상. 동물: 형태·무리/혼자·소리·머무는지/목적 있게 이동하는지. 자연현상: 다른 관측자와 자신에게의 의미. 동물/외계 존재/존재들 분류는 겹칠 수 있고 서술의 자유를 제한하지 않는다.

### 사건 (p.46–47, PDF 52–53)

**카드 한 장의 값과 색을 함께 해석**한다. 주사위나 동전은 필요 없다.

- **빨강**: 등대·섬의 피해, 자신에게 정신/신체의 지속 영향, 타인에게 해 등의 **오래가는 결과**.
- **검정**: 작은 방해·불편 등 **작은 결과**.
- 빨강=좋음/검정=나쁨으로 해석하면 틀린다. 색은 심각도/지속성이다.

| 값 | 사건 |
|---|---|
| 2 | 충돌 |
| 3 | 완전한 암전: 별/랜턴이 꺼지거나 우주 안개로 시야를 잃음 |
| 4 | 등대의 불빛이 꺼짐 |
| 5 | 갑자기 모든 것이 조용해짐 |
| 6 | 사랑하는 이의 편지/메시지 |
| 7 | 중력이 멈춤 |
| 8 | 우주 깊은 곳에서 신비한 신호/메시지 |
| 9 | 시간이 앞으로 휘어짐: **밤을 일찍 끝냄** |
| 10 | 조난 중인 우주선/배/비행체를 봄 |
| J | 혼자가 아님을 깨달음 |
| Q | 폭발 소리를 들음 |
| K | 시간이 뒤로 휘어짐: **밤을 다시 시작** |
| A | 여행자가 등대를 방문: 동물/외계인/인간 등 |

9/K는 단순 프롬프트에 그치지 않고 루프를 바꾸는 사건이다. 4는 불빛 유지 의무에 관련되므로 같은 화면에서 점등 규칙으로 빠르게 접근할 수 있어야 한다. K의 과거 기록 삭제·점수·강제 날짜 변경 규칙은 없으므로 그런 동작을 발명하면 안 된다.

## 4. 끝 절차 (p.48–49, PDF 54–55)

- 플레이 길이에 상한·하한 없음. 만족하면 끝낸다.
- 등대 위로 올라가 **불빛을 끈다**.
- 밤을 회상하며 덱을 섞는다: 조용하고 차분한 밤 **1회**, 꾸준한 밤 **2회**, 바쁜 밤 **3회**, 미친듯이 거칠고 무서운 밤 **4회**.
- 마지막 기록: 오늘 이후 감정, 달성/해결한 일, 미완료 일, 기억에 남을 것.
- 날짜·시간·처음 관찰·임무 결과·최종 소감이 하나의 밤 기록으로 이어져야 한다.
- 웹앱에서 덱을 섞는 UI는 이 단계의 기억/마감 행위와 연결되어야 한다. 무관한 곳의 장식적 셔플 버튼만으로 끝 규칙을 대체할 수 없다.

## 5. 미니게임 — 선택 콘텐츠지만 실제 도구가 필요

p.51(PDF 57): 미니게임은 밤의 어느 때나 원하는 횟수만큼 가능하며 본편과 별개로도 가능. 단 **A Light in the Dark의 개별 규칙은 밤당 응답 1회**여서 일반 설명보다 구체적 제약을 적용한다.

### Beachcombing / 우주 끝 수집 (p.52–55, PDF 58–61)

1. 시간을 보고 **시 ÷ 2**, 나누어 떨어지지 않으면 **올림**. 그 수만큼 발견할 물건/카드를 준비.
2. 그 수의 카드를 뒷면으로 놓는다.
3. **첫 카드만 공개**: 값으로 종류, 색으로 출처를 해석.
4. **카드 공개 후 동전을 뒤집어 상태**를 정한다.
5. 발견 기록을 쓰고 필요한 것을 가져간 뒤 **다음 카드**를 공개하여 반복.
6. 가치 있는 물건을 보관하고 다른 밤/임무 중 언제든 사용할 수 있다. 저장 물건 목록은 **세션 간 지속**되어야 한다.

출처: 빨강=알려진 출처, 검정=알 수 없는 출처. 상태는 작동/고장, 완전/불완전, 생존/죽음, 회수가능/불가, 부상/건강 등을 플레이어가 상황에 맞게 해석한다. **원문은 앞면=좋은 상태 등의 방향을 정하지 않는다.** 앱이 편의상 대응을 정하면 그것은 앱의 해석이라고 명시하거나 결과를 열린 상태로 남겨야 한다.

### A Light in the Dark / 어둠 속의 빛 (p.56–57, PDF 62–63)

- 여러 밤에 걸쳐 정체 모를 빛과 조금씩 알아간다. **질문을 먼저 떠올림 → 동전 2개 → 응답을 해석**.
- **한 밤에 응답 하나**.
- 앞/앞: 긍정·가까움·따뜻함·이해·만족·빛·미래·생명 등의 어휘군.
- 앞/뒤(뒤/앞도 같은 혼합): 아마도·중립·사이·고독·다른 곳·곧·기묘함·현재 등의 어휘군.
- 뒤/뒤: 부정·멀리·차가움·혼란·외로움·어둠·죽음·과거 등의 어휘군.
- 답은 예/아니오 버튼만이 아니다. 자유 질문에 대한 어휘군이므로 질문과 두 동전 및 해석이 함께 기록되어야 한다. 한 밤 한 번 제약과 여러 밤의 대화 연속성 지원이 핵심.

## 6. 계절 확장 — 본편 시작의 필수 절차 아님

p.59–60(PDF 65–66): 선택 확장. 세계에서 계절은 이틀 이상 지속하는 날씨 현상을 의미하며 예정된 지구 계절이 아니다. 지정된 기간 동안 계속되어야 한다. 관찰/정비를 어렵거나 불가능하게 할 수 있고, 지나간 뒤 큰 수리가 필요할 수 있다. 이 모든 영향은 서술로 다룬다.

**시작 방법 세 가지**:

1. 연결된 날씨를 관찰할 때 해당 계절의 원을 하나 표시한다. 다 채워지면 **다음 날 시작**하고 지정 기간 지속. **계절이 끝난 뒤** 원을 초기화한다.
2. 그날 날씨를 관찰할 때 계절을 직접 선택하여 시작.
3. **1d6**으로 계절 선택, **즉시 시작**.

| d6 | 계절 | 연결 날씨·원 수 | 기간 | 경고/특성/영향 요약 |
|---|---|---|---|---|
| 1 | Crowding Winds / 몰려드는 바람 | 폭풍, 5 | **4일** | 미풍과 속삭임→차갑고 강한 바람·많은 목소리. 귀마개 지침. 편집증·낮은 자존감·부분 청력 손실. p.61(PDF67) |
| 2 | Swallowing Fog / 삼키는 안개 | 바람, 5 | **1d6일** | 소리 사라짐·먼 별 흐림→반시간 내 반짝이는 흰 안개·따뜻함. 어지럼·방향 상실·시야 심각 제한. 움직이지 않고 등대 안에서 기다리는 대응. p.62(PDF68) |
| 3 | Hungry / 굶주린 자들 | 추움, 4 | **1d6일** | 경고 없음. 무언의 회색 그림자 무리; 보통 업무를 계속하며 무시, 그림자를 따라가지 않음. 불안·감시받는 감각. p.63(PDF69) |
| 4 | Dancing Lights / 춤추는 빛 | 따뜻함, 4 | **3밤** | 전날 희미한 빛→형태가 바뀌는 색색의 빛, 생물 증가. 경이로움; 악영향 없음. p.64(PDF70) |
| 5 | Thundering / 진동 | 맑은 밤, 4 | **2d6일** | 경고 없음. 섬과 등대 흔들림; 강할 때 섬 암석 부스러짐·물건 낙하/파손. p.65(PDF71) |
| 6 | Striking / 쏟아지는 충돌 | 유성우, 5 | **1d6 ÷ 2일** | 별똥별·잔해 증가→바위/잔해 소나기. 보호구, 창문 파손·멍·불면·극심한 구조 피해 가능. p.66–67(PDF72–73) |

계절에서 1d6/2d6/1d6÷2로 정한 기간이 길수록 강해진다. **Striking의 반 나눗셈에 올림/내림 지침이 없음**. 앱이 Math.ceil로 정수화하면 원문의 추가 해석이며 원문 충실성을 위해 0.5/1/1.5/2/2.5/3일을 그대로 표시하는 것이 가장 엄밀하다. Beachcombing은 올림 명시, 계절은 없음. 일(day)과 밤(night), 세션(session)은 동일하다고 명시되어 있지 않다. 실세계 캘린더나 앱 실행 횟수만으로 무조건 기간을 소모하는 것이 적절하다고 단정하면 안 된다.

빗날/강렬한 기이한 빛은 연결 계절명이 없다. 춤추는 빛은 **따뜻한 날씨에 누적**한다. Happy는 춥고 맑음이 함께 서술되어 Hungry와 Thundering의 연결 조건이 둘 다 나타날 수 있다. 원문은 하나로 자동 배타 분류하는 규칙이 없다.

## 7. 플레이북 — 통계/난이도 보정이 아니라 서술 렌즈

p.7–8(PDF 13–14): 여섯 캐릭터는 선택 가능한 출발점. 인물의 사연은 계속 변화하고, 잘하는/어려워하는 일은 **순수하게 서술 프롬프트**다. 판정은 그대로 하고 결과에 어떻게 반응하는지를 정한다. 불리한 일에도 예상 밖의 일이 유리하게 작용할 수 있으며, 능숙한 일도 결과가 안 좋으면 모든 기술을 써야 할 수 있다. 능숙함/약점이 주사위 보너스·재굴림·선택 제한·고정 성공을 주지 않는다.

## 8. Past Keepers’ Journal과 로그북의 역할

- p.68–83(PDF74–89)에는 지난 등대지기들의 예시 기록. 행동뿐 아니라 외로움·위안·호기심·불편·자기와 등대의 관계가 중심이며 서술 길이는 다양하다. 온도·날씨·Obs의 짧은 요약과 자유 서술이 함께 있음.
- 예시 글은 영감이지 추가 시스템 규칙이 아니다. 보급품·Guild·사라진 등대지기 등 세계 설정을 임무 추적/HP/경제 규칙으로 발명하지 않아야 한다.
- p.84(PDF90) 용어는 규칙 접근과 기록 어휘 보조에 유용: backwash(폭풍 뒤 잔해), crooks rest(아주 이른 아침), eye(등대 불빛), fat pig(호화선), glitter(방향감 잃게 하는 안개), island(등대가 있는 바위), light break(밤 끝/낮 시작), mealy(식용 사체), obs(관찰), scuttle ship(밀수선), wrecker(추락선).
- Logbook PDF2의 추가 용어: fixed beam(계속 비추는 고정 빛), lantern room(탑의 렌즈 유리방), service room(연료/보급품), quick light(보통 분당60회 빠른 점멸), quarters(거주방), rhythmic light(점멸 빔), tower, wickie(등대지기 별칭), wolf wind(울부짖는 강풍).
- Logbook PDF39의 측정 참고는 강제 입력/게임 수치 시스템 아님: 1 knot=1.85km/h=1.15mph; 1 beam=등대 빛 길이; AU·광년; 1 lux=표준 촛불; beacon=10,000 lux; 풍력 단계0–12(무풍부터 허리케인).
- Paper Lighthouse(p.86–88/PDF92–94)는 인쇄 공예/분위기 보조이며 앱의 기본 루프 기능 우선순위가 아니다. 뒤 출판 광고/크레딧/표지는 추가 규칙 없음.

## 9. 앱 감사/검증에 사용할 필수 체크

### 정확성

- 날짜/시간 시작, 감정에 따른 날씨 **선택**, 점등 동일 시도 H+red, 실패 반복, 태엽 감기.
- 정비/관찰의 주사위 표·문양 표 정확, 사건 값·색 해석 정확.
- 9 종료, K 재시작 동작 지원; 4 점등 규칙의 즉시 참조.
- 선택한 임무 처리 뒤 **기록→다음 임무 선택** 자연스럽게 이어짐.
- 종료 만족 기준·소등·1–4회 셔플·마무리 기록 지원.
- Beachcombing 시÷2 올림, 순차 카드+각 동전, 알려짐/미지 출처, 세션간 보관 목록.
- Dark 질문→2동전→열린 해석, 밤당1회 응답, 지난 대화 지속.
- 계절 선택 확장, 세 가지 시작, 누적 후 다음 날 시작, 기간, 종료 때 원 초기화, 주사위 합/반값.
- 플레이북 서술 전용, 기본 플레이 필수 설정 아님.

### 빠른 접근과 인지 부하

- 당장 필요한 결과 해석이 판정 도구 옆에 있어 따로 규칙 메뉴나 PDF를 열지 않아도 되는가.
- 진행 중 날짜/날씨/계절/점등 상태를 확인하려고 화면 여러 곳을 탐색하지 않는가.
- 임무 선택에서 필요한 결과와 기록까지의 조작 수가 적은가.
- 판정 결과·사용한 도구 값·기록 맥락을 잃지 않는가.
- 기록 완료 뒤 다시 전체 규칙 카탈로그를 헤매지 않는가.
- 선택 콘텐츠의 메뉴가 쓰기/핵심 임무보다 시각적으로 커서 읽기 부담을 만들지 않는가.
- 모바일에서 기록과 판정이 멀리 분리되지 않는가. 넓은 데스크톱은 쓰기와 참고를 나란히 둘 수 있으나 좁은 화면에는 반복·빈 패널이 없는가.

## 10. 원문에서 결정되지 않은 것 — 구현이 규칙으로 단정하면 안 되는 부분

- 카드 덱 고갈 시 처리/복원추출 여부가 명시되지 않음. 52장 표준 카드, Joker 표 없음. 종료 셔플 의식은 명시됨.
- Beachcombing 동전 앞/뒤에 상태의 긍정/부정을 배정하지 않음.
- Beachcombing 시의 12/24시간 형식·0시 처리 없음. 시를 사용자가 선택·수정할 수 있게 하면 불필요한 해석 강제가 적음.
- Striking 기간1d6÷2의 반올림 규칙 없음. 0.5일 단위 그대로 쓰거나 앱의 관습을 드러내야 함.
- 계절의 day vs night vs 세션 관계, 복수 계절 동시 가능, 트래커를 자동으로 하나만 증가시키는 규칙은 없음.
- K 재시작의 기록 삭제·날짜 뒤로 이동·모든 진행 롤백 규칙 없음. 이미 쓴 기록은 보존하는 것이 안전함.
- 4 불빛 꺼짐 뒤 재점등 판정은 직접 적혀 있지 않으나 불빛 유지 의무와 기존 점등 절차를 참조하는 대응은 자연스럽다.
- 원문 프롬프트는 개방적. 자동 생성 문장을 완성된 자기 기록으로 간주하거나 판정 수만 증가해도 임무 완료로 간주하면 저널링 목적을 약화한다.
